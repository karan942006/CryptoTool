3. PROPOSED SOLUTION (CONCISE SUMMARY)
--------------------------------------------------------------------------------
* What are you building?
  An automated cybersecurity platform that scans source code archives and live network endpoints to create an exhaustive Cryptographic Bill of Materials (Crypto-BOM / CBOM), scores security risk mathematically, and guides migration to Post-Quantum Cryptography (PQC).
* What is the core idea?
  Organizations are blind to what encryption, hashing, and keys are running inside their software. CryptoTool provides 100% visibility into this "cryptographic debt" and identifies algorithms that will collapse under quantum computers.
* Who will use it?
  - National Security & Defense Agencies (NTRO, CERT-In, Defense forces).
  - Banking & Financial Sector (RBI, NPCI, Fintechs).
  - Enterprise AppSec & DevSecOps Teams.
* What problem does it solve?
  The "Harvest Now, Decrypt Later" (HNDL) quantum threat, legacy broken ciphers (MD5, SHA-1, 3DES, RSA-1024), hardcoded secret keys, and non-compliance with global PQC standards (NIST FIPS 203/204).
* What makes it different?
  Unlike general SAST tools (SonarQube) or regex scanners (Semgrep), CryptoTool reconstructs full cryptographic context (key lengths, cipher modes, curves) using AST analysis, performs live TLS handshakes, produces standard Crypto-BOMs, and uses 100% deterministic scoring with zero AI hallucinations.

--------------------------------------------------------------------------------
4. DETAILED EXPLANATION OF THE SOLUTION & WORKING
--------------------------------------------------------------------------------
Major Modules:
1. Multi-Language Ingestion & AST Scanner: Parses Java, Kotlin, Python, JS/TS, and C/C++ source code into Abstract Syntax Trees to find crypto calls without executing code.
2. Network TLS & X.509 Certificate Auditor: Simulates non-intrusive TLS 1.0-1.3 client handshakes on live domains to inspect server cipher suites, key exchanges, and certificates.
3. Cryptographic Normalization Engine: Translates hundreds of custom library aliases (e.g., "AES/CBC/PKCS5Padding", "CIPHER_AES_128") into standardized NIST cryptographic primitives.
4. Deterministic Risk & PQC Engine: Evaluates findings against NIST SP 800-57, NIST SP 800-131A, and Shor/Grover quantum algorithms to compute a 0-100 score.
5. Grounded AI Security Analyst: Gemini 1.5 Flash provides code-level refactor explanations based strictly on verified findings (sandboxed, cannot invent CVEs).
6. Crypto-BOM & Reporting Engine: Generates CycloneDX v1.6 CBOM (JSON/CSV) and high-resolution Executive PDF assessment reports.

User & System Workflow:
User uploads zip/repo or inputs HTTPS URL -> Zip-slip & path traversal sanitization -> AST parsing / TLS handshake -> Canonical primitive extraction & secret redaction -> Rule-based deterministic risk scoring -> PQC vulnerability mapping -> Web Dashboard display + CBOM export + PDF download.
